## Workflow pour déposer les images

1. Générez chaque image avec l'outil IA de votre choix en utilisant le prompt ci-dessus
2. Nommez le fichier exactement comme indiqué (ex: `hero-main.jpg`)
3. Sur GitHub, naviguez dans le bon sous-dossier (ex: `public/images/services/`)
4. Cliquez **Add file → Upload files**
5. Glissez-déposez vos images et committez

Les images remplaceront automatiquement les placeholders Unsplash actuellement utilisés dans le code.
